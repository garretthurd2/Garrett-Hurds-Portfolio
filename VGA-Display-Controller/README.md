# VGA Display Controller


#About
Designed a 640x480 @ 60 Hz VGA display controller in VHDL on a Digilent Basys 3 (Artix-7) in Vivado, generating horizontal and vertical sync timing from a 25 MHz pixel clock derived from the 100 MHz system clock. Wrote numbered, traceable requirements before RTL and verified sync pulse widths, porch timing, and frame period with self-checking testbenches, then closed timing with positive slack under XDC clock constraints and brought the design up on a monitor.
